# Помочь может и новичок

Самый полезный вклад — воспроизводимый результат. Не обязательно разбираться в Wine: достаточно описать, что вы сделали и что увидели.

## Сообщить об ошибке или успешном запуске

[Создайте issue](https://github.com/anrhangels/samp-linux-lab/issues/new/choose) и укажите проект, сервер, дату, версии Linux, рабочего стола, драйвера, Faugus и Proton. Приложите точные шаги, текст ошибки и результат одного изменения.

Отдельно отметьте, что проверили: открытие лаунчера, вход на сервер, передвижение, русский чат, голос с другим игроком, повторный запуск. Не отмечайте игру рабочей только по заставке.

Для нового проекта используйте отдельный префикс. Непроверенные варианты обозначайте прямо. Amazing закрыт по решению владельца; сохранённый отчёт не является планом возобновления работ.

## Изменить документацию или код

1. Сделайте fork и отдельную ветку.
2. Внесите одно понятное изменение. Для обхода ошибки опишите исходный симптом, действие, результат и откат.
3. Для изменений скриптов выполните проверки ниже.
4. Откройте pull request и укажите, что проверено автоматически и что — в игре.

```bash
python3 -m unittest discover -s tests -v
bash -n scripts/arizona.sh
```

Используйте относительные ссылки между документами и официальные источники загрузок. Тесты с временными файлами не должны менять реальную конфигурацию пользователя. Для сравнения FPS сохраняйте сцену и графические настройки, меняйте один параметр за раз; максимальный FPS не равен среднему.

Перед публикацией просмотрите вложения и уберите пароли, токены, данные аккаунта, чат и личные пути. Игровые бинарники, префиксы, дампы памяти и чужие шрифты в репозиторий не добавляются.
