# Как дополнить SA-MP Linux Lab

Для нового проекта создайте отдельный префикс и опишите проверку в `docs/`. В таблицу запущенных добавляйте только проект, для которого подтверждён вход в игру; остальные оставляйте в кандидатах.

В отчёте укажите:

- Проект и сервер; дату проверки и версии лаунчера/клиента.
- Дистрибутив, рабочую среду, Wayland/X11, CPU/GPU и драйвер.
- Версии Faugus, Proton и umu; тип установки Faugus.
- Шаги установки, исходную ошибку, конкретное изменение и результат.
- Что проверено отдельно: вход, передвижение, русский чат, голос, повторный запуск.
- Как отменить изменение и где остаются ограничения.

Для сравнения производительности меняйте один параметр за раз, используйте один маршрут и сохраняйте графические настройки. Не выдавайте максимальный FPS за средний.

Перед публикацией удалите из отчёта пароли, токены, чат, данные аккаунта и личные пути. Не загружайте игровые бинарники, префиксы или чужие шрифты. Собственные изменения скриптов проверяйте командой `python3 -m unittest discover -s tests -v`.
