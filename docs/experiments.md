# Журнал экспериментов

Сессия 2–3 ноября 2026 года. Наблюдения одного пользователя на одной системе.

| Изменение | Наблюдение | Решение |
|---|---|---|
| Faugus + установленный GE-Proton 11-11 | Официальный лаунчер и игра запустились | Рабочая основа |
| Конкретная версия вместо Latest | Обход неудачной автоматической загрузки | Использовать установленную сборку |
| Старая авторизация | Регистрация прошла после ошибки новой формы | Оставлена |
| Перенос файлов `:Zone.Identifier` | Ошибки загрузки шрифтов при старте устранены | Описан точечный обход |
| Профиль питания Performance | Сообщён рост наблюдаемого FPS ~90 → ~120 | Оставлен пользователем |
| Лимит 60 FPS | Не соответствует цели повышения производительности | Снят |
| Главный поток только на P-ядрах | Субъективно заметной разницы нет | Назначение восстановлено |
| Wine Wayland | Русское управление не исправлено; смещение кликов | Возвращён Xwayland |
| MangoHud через доступные библиотеки/манифесты | Панель появилась, три режима работают | Рабочая диагностика |
| Strict float emulation в DXVK | Мерцание не исчезло, заметного изменения FPS нет | Откат |
| Разные уровни сглаживания | Мерцание осталось | Не считать причиной |
| GE-Proton 11-10 вместо 11-11 | Мерцание осталось | Рекомендован возврат 11-11 |
| Мерцание рядом с Halloween-декором | На записи меняются ореолы фонарей при движении | Причина не установлена |

Гипотеза о праздничном эффекте не подтверждена. Для проверки нужен обычный фонарь вдали от декора и тот же маршрут на другом клиенте/Windows. По записи нельзя уверенно диагностировать все скачки поверхности земли.

Первая версия измерителя CPU ошибочно использовала накопленную статистику процесса вместо интервальной статистики главного потока. Эти проценты нельзя использовать как доказательство насыщения одного ядра. Исправленный тест назначения ядер не записывал FPS, поэтому прирост им не доказан.

GPU-замер длительностью 60 секунд: средняя загрузка около 34%, температура 50–54 °C. Это показывает запас GPU в том эпизоде, но не доказывает постоянный CPU bottleneck во всех сценах.


## Как была выстроена работа

### Окружение и установка

Сначала подготовлено окружение Faugus Flatpak и отдельный префикс. Автоматический выбор Latest не смог получить компоненты из-за HTTP 403 GitHub API. После выбора установленной GE-Proton 11-11 и подготовки umu удалось запустить официальный лаунчер. Запись переключена с установщика на установленный EXE. Клиент загружен средствами самого лаунчера.

### Вход и управление

Новая форма авторизации принимала ввод, но отклоняла отправку. Переход на старую форму позволил зарегистрироваться и войти на сервер. Проверены чат и управление: на английской раскладке управление работает, на русской буквенные клавиши перестают выполнять игровые действия. Изменение preload раскладок и переход на Wine Wayland не дали полноценного исправления. Возврат к Xwayland устранил побочный эффект со смещёнными кликами.

### Ошибки клиента и шрифты

Проверка файлов выявила отдельные `:Zone.Identifier`, которые попадали в обработку шрифтов. Служебные файлы перенесены в резервную папку, настоящие шрифты сохранены. Соответствующие окна ошибок исчезли. Отдельно исследованы вопросительные знаки в AZRTC: проверялись Segoe UI/Arial, заменители DejaVu Sans и точные имена `segoeui.ttf`/`seguisb.ttf`. Исправление всех подписей не подтверждено. Эмодзи позднее отображались в игровых CEF-диалогах, но полный охват символов не проверен.

### Экран и наблюдение

Проверены профили 1920×1080 и 2560×1600. В Hyprland физическое разрешение стало доступно после настройки масштаба Xwayland. Список видеорежимов до двух вариантов ограничить не удалось. Для наблюдения подготовлена панель MangoHud с минимальным, подробным и скрытым режимами. Из-за различий пространств Flatpak и Steam Runtime использованы локальные библиотеки и манифесты с абсолютными путями.

### Производительность и визуальные дефекты

Сравнивались профиль питания, ограничение FPS, назначение P-ядер, сглаживание, DXVK strict float и GE-Proton 11-10. Пользователь отметил изменение FPS после включения Performance; остальные перечисленные тесты не подтвердили решение мерцания. Неудачные изменения отменялись.

### Что перенесено в общедоступный инструмент

Локальные команды содержали пути конкретного пользователя и экспериментальные изменения реестра. Для репозитория выделены операции с понятными границами: запуск существующей записи, локальный лог, настройка HUD с копией конфигурации и обратимый перенос служебных файлов рядом со шрифтами. Подмена голосовых модулей, эксперименты с реестром и завершение всех Wine-процессов не автоматизированы.

Обновлённый помощник проверяется тестами на временных данных. Новый сквозной запуск игры после переоформления репозитория не проводился; подтверждённый игровой результат относится к исходной сессии.
