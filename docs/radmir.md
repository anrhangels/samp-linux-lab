# Radmir CRMP (GTA San Andreas)

4 ноября 2026 года подтверждён запуск игры с новой графикой: на тестовом компьютере наблюдалось 70–90 FPS. Исправлены сбои компиляторов шейдеров и загрузки музыки. Это результат одного окружения; автоматическая установка с нуля целиком ещё не проверена.

## Установка одним файлом

Нужны Linux x86_64, Python 3.12+, Flatpak, `xrandr` и рабочие Vulkan-драйверы, включая поддержку 32-битных игр. Проверяли Arch Linux с Hyprland/Xwayland и NVIDIA RTX 4060 Laptop. Установка системных пакетов и драйверов остаётся за пользователем.

Скачайте [install-radmir.py](../scripts/install-radmir.py) или выполните:

```bash
curl -fL https://raw.githubusercontent.com/anrhangels/samp-linux-lab/main/scripts/install-radmir.py -o install-radmir.py
python3 install-radmir.py --check
python3 install-radmir.py
```

Запускайте без `sudo`. Скрипт при необходимости устанавливает Faugus Flatpak, UMU 1.4.4-patch, GE-Proton11-11 и MangoHud. Он скачивает установщик с сервера обновлений, указанного в официальном лаунчере, и сверяет EXE с SHA-512 из `latest.yml`. Затем устанавливает Microsoft UCRT, D3DX9_43, D3DCompiler_43/47 и создаёт команду запуска.

После установки:

```bash
radmir
```

При первом запуске выберите **RADMIR CRMP** в официальном лаунчере и дождитесь загрузки игровых файлов. Введите свой никнейм. Можно выбрать новую графику. Скрипт не создаёт игровой аккаунт и не содержит паролей или игровых файлов.

Если команда не найдена, используйте `~/.local/bin/radmir` и добавьте `~/.local/bin` в `PATH` вашей оболочки.

## Что делает запуск

- Использует отдельный префикс `~/Games/radmir-crmp/prefix`.
- На время сеанса выбирает существующий экран 1920×1080 основным в Xwayland, если такой экран подключён. Разрешение, масштаб и расположение экранов не меняются; прежний основной экран восстанавливается после выхода. Без такого экрана используются текущие настройки.
- Включает MangoHud: F10 меняет режим, F12 скрывает панель.
- Исправляет кириллицу в адресах музыки через локальный HTTP-посредник. Он слушает только `127.0.0.1` на свободном порту. Настройки прокси меняются только в префиксе Radmir; остальные запросы лаунчера передаются без преобразования адресов.

Оставляйте терминал открытым до выхода из игры и лаунчера: процесс обслуживает загрузку музыки. После завершения прежние настройки прокси восстанавливаются. При аварийном завершении сохранённые настройки восстанавливаются при следующем запуске. Для отдельного восстановления:

```bash
radmir --restore
```

Повторная установка использует уже установленный лаунчер и проверяет наличие библиотек. Перед заменой библиотек сохраняются их копии и реестры. Логи и резервные копии находятся в `~/.local/state/radmir-lab/`. Автоматического отката всей установки нет; папка `backup` содержит исходные файлы для восстановления.

## Причины исправлений и проверка

В новой графике обнаружены сбой `strftime` во встроенной UCRT Wine и неподдерживаемые эффекты `fx_2_0` в D3DX. С оригинальными библиотеками Microsoft игра запустилась.

Обычные звуки работали, но BASS не открывала MP3 по адресам с кириллицей Windows-1251: ошибка `2`. В отдельном процессе с той же игровой `bass.dll` адрес UTF-8 открывался успешно. После преобразования адресов открылись все четыре проверенных варианта; пользователь подтвердил отсутствие прежней ошибки в игре. DLL игры не подменяются.

Проверены синтаксис встроенных модулей, целостность архива, разбор метаданных обновления, передача ожидаемой SHA-512 и проверка формата EXE на локальных данных. Сценарии повторной и чистой установки проверены с имитацией внешних запусков. Полную свежую установку, сетевые загрузки и тихий режим установщика ещё нужно проверить в обычном пользовательском сеансе.

## Исходники

Для установки достаточно одного файла `scripts/install-radmir.py`; зависимости загружаются из сети. Его вспомогательные модули встроены в сжатом виде. Читаемые копии находятся в [scripts/radmir](../scripts/radmir/).

После изменения исходников пересоберите установщик:

```bash
python3 scripts/build_radmir_bundle.py
python3 scripts/install-radmir.py --check
```
