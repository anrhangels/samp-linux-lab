# Arizona: проверенная основа и границы результата

## Запуск

Проверена официальная Windows-версия Arizona Games Launcher 0.0.144. Установка выполнена внутри отдельного префикса Faugus. Пример Windows-пути:

```text
C:\users\steamuser\AppData\Local\Programs\Arizona Games Launcher\Arizona Games Launcher.exe
```

Путь Linux зависит от выбранного префикса. В записи Faugus должен находиться именно установленный файл, а не загруженный установщик.

Автовыбор `GE-Proton Latest` первоначально не загрузил компоненты из-за HTTP 403 GitHub API (лимит неавторизованных запросов). Выбор уже установленного GE-Proton 11-11 и установка umu позволили продолжить.

В интерфейсе Faugus конкретную сборку проще обнаружить по имени в стандартном каталоге `~/.local/share/Steam/compatibilitytools.d/`. Если она установлена Steam Flatpak, может потребоваться доступ Faugus на чтение её каталога и символическая ссылка в стандартном каталоге. Давайте доступ только к нужной папке. После изменения разрешений полностью перезапустите Faugus.

## Регистрация и ввод

Новая CEF-форма принимала латиницу и показывала валидность пароля, но отклоняла отправку. Отключение «Новой авторизации» позволило зарегистрироваться. Не доказано, что первопричина — Wine или раскладка. Не публикуйте пароль и не проверяйте его в открытых полях формы.

Управление работает на английской раскладке. На русской буквенные клавиши в нашем тесте переставали работать как управление. Постоянное исправление не найдено; переключение на английскую — временный обходной способ. Изменения preload раскладок и тест Wayland полноценного исправления не дали.

## Разрешение и мышь

Для ноутбука доступен режим 2560×1600@165; для другого экрана использовался 1920×1080. Частоту нужно выбирать из реально поддерживаемых монитором режимов. Два сохранённых профиля не означают, что список всех режимов игры удалось сократить до двух.

В Hyprland `xwayland.force_zero_scaling=true` помогло игре увидеть физическое разрешение. Это глобальная настройка Xwayland и может изменить размер других старых приложений; она не применяется нашим CLI автоматически. См. [документацию Hyprland](https://wiki.hypr.land/configuring/extra/xwayland/).

Тест нативного Wayland-драйвера Proton не решил раскладку и сопровождался несовпадением координат мыши. Возвращён Xwayland.

## Шрифты и голос

В загруженном клиенте обнаружились отдельные файлы `font.ttf:Zone.Identifier`. Игра пыталась открыть их как шрифты. Перенос только таких служебных файлов в резервную папку, при наличии настоящего одноимённого файла без суффикса, устранил соответствующие окна ошибок. Удалять настоящие `.ttf`, DLL или ASI не требуется. Лаунчер может восстановить служебные файлы при обновлении.

Логи AZRTC подтверждали выбор микрофона PulseAudio и соединение с голосовым сервером. Передача речи другим игрокам требует отдельной проверки. На сервере отображалось ограничение голосового чата с 5-го уровня. Также было предупреждение о несовпадении версий клиента и сервера — самостоятельно подменять модуль из случайных источников не следует.

В меню AZRTC русские подписи отображались вопросительными знаками. Проверялись Segoe UI/Arial и кириллические заменители DejaVu Sans. Одной регистрации заменителей не хватило; затем добавлялись файлы по точным именам `segoeui.ttf` и `seguisb.ttf`. Изолированного подтверждения исправления всех подписей нет. Поэтому этот эксперимент не включён как гарантированный автоматический фикс.

Для эмодзи установлены Noto Color Emoji на Linux и Segoe UI Emoji из уже имеющихся ресурсов клиента в префикс. В игровых CEF-диалогах позднее видны эмодзи. Полный охват символов в игре и Steam отдельно не проверен. Шрифты не включены в репозиторий.
