# Arizona RP на Linux

**Статус:** запущен официальный лаунчер, выполнены регистрация и вход в игру на Mesa. Работает игровой чат; голосовой модуль соединяется с сервером. Проверка: 2–3 ноября 2026 года.

[← На главную](../README.md) · [Команды помощника](toolkit.md) · [Решение проблем](troubleshooting.md) · [Официальные загрузки](sources.md)

## Установка по шагам

### 1. Подготовить Faugus

Установите Faugus Flatpak по [быстрому старту](quickstart.md) и дождитесь загрузки umu. Через менеджер Proton установите конкретную сборку: в проверенной конфигурации — GE-Proton 11-11. Для этой инструкции используйте Xwayland, если работаете в Wayland-сессии.

### 2. Скачать официальный установщик

Откройте [arizona-rp.com](https://arizona-rp.com/) в браузере, выберите загрузку для Windows и сохраните установщик. Название файла может меняться. Не путайте скачанный установщик с установленным лаунчером.

### 3. Создать запись

В Faugus добавьте Windows Game. Укажите скачанный установщик, отдельный префикс `~/Faugus/arizona` и установленную сборку GE-Proton. Название записи может быть любым; её внутренний ID понадобится скрипту. Запустите установку и выберите установку «только для меня». Пользователь `steamuser` внутри префикса — нормальная часть Proton.

### 4. Заменить путь на установленный лаунчер

После установки отредактируйте ту же запись Faugus: сохраните префикс и Proton, а путь к установщику замените на:

```text
~/Faugus/arizona/drive_c/users/steamuser/AppData/Local/Programs/Arizona Games Launcher/Arizona Games Launcher.exe
```

В файловом диалоге выберите реальный путь внутри своего домашнего каталога. Не вводите `~` как буквальную часть имени файла. Если установили в другое место, найдите EXE внутри выбранного префикса.

### 5. Загрузить клиент

Откройте запись Faugus. В официальном лаунчере выберите Arizona и загрузите клиент. Дождитесь окончания проверки файлов, затем выберите сервер. Для воспроизведения нашей сессии использовалась Mesa. Перед долгой загрузкой проверьте действия системы при простое: компьютер не должен выключиться.

### 6. Проверить запуск помощником

Из корня скачанного репозитория выполните:

```bash
python3 scripts/samp_linux.py list
bash scripts/arizona.sh check
bash scripts/arizona.sh launch
```

Если ID отличается от `arizona-launcher`, добавьте `--game ВАШ_ID`. Команда запуска использует настройки существующей записи и печатает путь к новому логу.

### 7. Пройти проверку в игре

Проверьте вход, передвижение на английской раскладке, мышь и отправку чата. При ошибке регистрации попробуйте старую форму авторизации. Настройте разрешение под монитор. Голос проверяйте отдельно с другим игроком после достижения требуемого сервером уровня.

## Исправления и настройки

Ниже — подробности выполненной работы и её ограничения. Меняйте по одному параметру и проверяйте результат после перезапуска.


### Runner, umu и доступ к файлам

Проверена официальная Windows-версия Arizona Games Launcher 0.0.144. Установка выполнена внутри отдельного префикса Faugus. Пример Windows-пути:

```text
C:\users\steamuser\AppData\Local\Programs\Arizona Games Launcher\Arizona Games Launcher.exe
```

Путь Linux зависит от выбранного префикса. В записи Faugus должен находиться именно установленный файл, а не загруженный установщик.

Автовыбор `GE-Proton Latest` первоначально не загрузил компоненты из-за HTTP 403 GitHub API (лимит неавторизованных запросов). Выбор уже установленного GE-Proton 11-11 и установка umu позволили продолжить.

В интерфейсе Faugus конкретную сборку проще обнаружить по имени в стандартном каталоге `~/.local/share/Steam/compatibilitytools.d/`. Если она установлена Steam Flatpak, может потребоваться доступ Faugus на чтение её каталога и символическая ссылка в стандартном каталоге. Давайте доступ только к нужной папке. После изменения разрешений полностью перезапустите Faugus.

### Регистрация и ввод

Новая CEF-форма принимала латиницу и показывала валидность пароля, но отклоняла отправку. Отключение «Новой авторизации» позволило зарегистрироваться. Не доказано, что первопричина — Wine или раскладка. Не публикуйте пароль и не проверяйте его в открытых полях формы.

Управление работает на английской раскладке. На русской буквенные клавиши в нашем тесте переставали работать как управление. Постоянное исправление не найдено; переключение на английскую — временный обходной способ. Изменения preload раскладок и тест Wayland полноценного исправления не дали.

### Разрешение и мышь

Для ноутбука доступен режим 2560×1600@165; для другого экрана использовался 1920×1080. Частоту нужно выбирать из реально поддерживаемых монитором режимов. Два сохранённых профиля не означают, что список всех режимов игры удалось сократить до двух.

В Hyprland `xwayland.force_zero_scaling=true` помогло игре увидеть физическое разрешение. Это глобальная настройка Xwayland и может изменить размер других старых приложений; она не применяется нашим CLI автоматически. См. [документацию Hyprland](https://wiki.hypr.land/configuring/extra/xwayland/).

Тест нативного Wayland-драйвера Proton не решил раскладку и сопровождался несовпадением координат мыши. Возвращён Xwayland.

### Шрифты и голос

В загруженном клиенте обнаружились отдельные файлы `font.ttf:Zone.Identifier`. Игра пыталась открыть их как шрифты. Перенос только таких служебных файлов в резервную папку, при наличии настоящего одноимённого файла без суффикса, устранил соответствующие окна ошибок. Удалять настоящие `.ttf`, DLL или ASI не требуется. Лаунчер может восстановить служебные файлы при обновлении.

Логи AZRTC подтверждали выбор микрофона PulseAudio и соединение с голосовым сервером. Передача речи другим игрокам требует отдельной проверки. На сервере отображалось ограничение голосового чата с 5-го уровня. Также было предупреждение о несовпадении версий клиента и сервера — самостоятельно подменять модуль из случайных источников не следует.

В меню AZRTC русские подписи отображались вопросительными знаками. Проверялись Segoe UI/Arial и кириллические заменители DejaVu Sans. Одной регистрации заменителей не хватило; затем добавлялись файлы по точным именам `segoeui.ttf` и `seguisb.ttf`. Изолированного подтверждения исправления всех подписей нет. Поэтому этот эксперимент не включён как гарантированный автоматический фикс.

Для эмодзи установлены Noto Color Emoji на Linux и Segoe UI Emoji из уже имеющихся ресурсов клиента в префикс. В игровых CEF-диалогах позднее видны эмодзи. Полный охват символов в игре и Steam отдельно не проверен. Шрифты не включены в репозиторий.


### Точечное исправление ошибок шрифтов

```bash
# Сначала только посмотреть найденные служебные файлы
bash scripts/arizona.sh fix-fonts
# После закрытия игры, лаунчера, Faugus и приложений Wine
bash scripts/arizona.sh fix-fonts --apply
```

Сохраняется резервная копия и план восстановления. Команда не заменяет шрифты и не исправляет автоматически вопросительные знаки в AZRTC. [Подробности и откат](toolkit.md#исправление-служебных-файлов-шрифтов).

### FPS и питание

При питании от сети пользователь включил системный профиль Performance и сообщил рост наблюдаемого FPS примерно с 90 до 120; позднее в отдельных сценах было около 160. Это не результат контролируемого сравнения и не прогноз для другого компьютера. Профиль выбирается вручную в настройках питания своей системы; скрипт его не меняет.

Привязка главного потока к P-ядрам заметного выигрыша не дала и была отменена. Постоянный лимит 60 FPS снят. Панель наблюдения настраивается командой `bash scripts/arizona.sh hud` — [описание режимов](toolkit.md#панель-mangohud).

## Открытые вопросы

| Симптом | Текущее состояние | Что делать сейчас |
| :--- | :--- | :--- |
| Буквенное управление пропадает в русской раскладке | Постоянного исправления нет | Переключать управление на английскую |
| Лаунчер пишет об ошибке, но игра уже работает | Причина не установлена | Не запускать второй экземпляр; проверить окно игры |
| Русские подписи AZRTC отображаются вопросами | Эксперименты со шрифтами не дали изолированного подтверждения | Не применять неподтверждённые замены как обязательный фикс |
| Голосовой модуль соединён, но передача речи не проверена | Требуется собеседник и доступ по уровню | Проверить микрофон, разрешения и правила сервера |
| Мерцание света/окружения | DXVK strict float, сглаживание и смена Proton не помогли | Сравнить одинаковый маршрут вдали от декора; сохранить наблюдения |
| Список разрешений содержит лишние варианты | Ограничение списка двумя режимами не реализовано | Выбрать подходящий режим вручную |

Полная последовательность сравнений и неудачных попыток: [журнал экспериментов](experiments.md).

## Что проверить после обновления

1. Не сбился ли путь записи Faugus на установщик.
2. Осталась ли выбрана проверенная сборка Proton.
3. Завершилась ли проверка файлов клиента.
4. Не вернулись ли служебные файлы `:Zone.Identifier`.
5. Работают ли ввод, чат, разрешение и HUD после полного перезапуска.

Не переносите готовый префикс поверх другой игры. Для нового проекта повторите установку отдельно и зафиксируйте собственные результаты.
