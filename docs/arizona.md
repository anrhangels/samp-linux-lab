# Arizona RP: установка и первый вход

**Подтверждено:** официальный лаунчер, регистрация, вход на Mesa, передвижение и чат. Проверка проведена 2–3 ноября 2026 через Faugus Flatpak и GE-Proton 11-11 на Arch / Hyprland / Xwayland. Полная передача голоса не проверена.

## 1. Скачайте установщик

Откройте [официальный сайт Arizona](https://arizona-rp.com/) в браузере и скачайте Windows-лаунчер. Сохраните файл в обычной папке загрузок.

## 2. Создайте запись Faugus

В Faugus добавьте Windows-игру и выберите скачанный установщик как исполняемый файл. Для неё создайте отдельный префикс, например `~/Faugus/arizona`, и выберите установленный GE-Proton.

Запустите эту запись и пройдите установку лаунчера. В проверенной установке выбран вариант **«только для меня»**. Имя Windows-пользователя `steamuser` в префиксе Proton — нормальное поведение.

## 3. Переключите запись на установленный лаунчер

Закройте установщик. В **той же записи Faugus** замените путь к EXE на установленный `Arizona Games Launcher.exe`.

Пример расположения:

```text
~/Faugus/arizona/drive_c/users/steamuser/AppData/Local/Programs/Arizona Games Launcher/Arizona Games Launcher.exe
```

Ваш путь может отличаться. В диалоге выбора файла переходите в свою домашнюю папку: символ `~` в примере обозначает её, а не имя каталога. Префикс и Proton оставьте выбранными для этой записи.

Ожидаемый результат — запускается лаунчер, а не повторная установка.

## 4. Загрузите клиент и войдите

Откройте лаунчер через Faugus и загрузите клиент его средствами. Выберите сервер, запустите игру и проверьте вход.

Если новая форма регистрации принимает текст, но не отправляет его, попробуйте отключить **«Новую авторизацию»** в настройках лаунчера. В нашей сессии старая форма позволила зарегистрироваться; точная причина сбоя новой формы не установлена.

Перед проверкой передвижения переключитесь на английскую раскладку. Русская раскладка в тестовой системе нарушала управление буквенными клавишами.

## 5. Подключите удобный запуск

Из папки этого репозитория:

```bash
python3 scripts/samp_linux.py list
bash scripts/arizona.sh check
bash scripts/arizona.sh launch
```

Если ID вашей записи отличается от `arizona-launcher`, используйте его явно:

```bash
bash scripts/arizona.sh check --game ваш-id
bash scripts/arizona.sh launch --game ваш-id
```

`ваш-id` замените на значение из `list`. Успешный `check` подтверждает наличие основных файлов, но реальный вход проверяется в игре. Каждый запуск через скрипт сохраняет лог; путь печатается в терминале.

## Известные ограничения

| Что заметили | Как действовать |
| :--- | :--- |
| Управление ломается на русской раскладке | Играть на английской; постоянного решения пока нет |
| Ошибки загрузки шрифтов | Проверить служебные файлы по [инструкции с откатом](toolkit.md) |
| Лаунчер пишет об ошибке, а игра уже работает | Проверить окна и не запускать второй экземпляр |
| Неверное разрешение или смещены клики | Сверить масштабирование Xwayland; подробности ниже |
| Голосовой модуль подключён, но речи не слышно | Проверить микрофон, разрешения и ограничения сервера; на тестовом сервере требовался уровень 5 |
| В голосовом интерфейсе вместо кириллицы вопросы | Надёжный универсальный фикс не найден |
| Мерцают ореолы фонарей | Проверенного исправления нет; старые DXVK-эксперименты не помогли |

## Разрешение и производительность

Наблюдалась работа в 1920×1080 и 2560×1600 при 165 Гц на подходящем мониторе. Это не обязательные настройки.

В тестовой Hyprland настройка `xwayland.force_zero_scaling = true` помогла получить физическое разрешение. Она действует и на другие Xwayland-приложения и может изменить их масштаб. Сначала сохраните прежнее значение. Нативный Wine Wayland в этой сессии не исправил раскладку и смещал клики; рабочая основа — Xwayland.

Профиль питания Performance от сети сопровождался наблюдаемым ростом FPS примерно с 90 до 120; позднее встречалось 160. Контролируемого сравнения не было: это не обещание прироста. Назначение P-ядер заметного улучшения не дало. [Подробные результаты](experiments.md).

## После обновления клиента

Проверьте, что запись Faugus всё ещё указывает на установленный EXE, выбран прежний Proton и проверка файлов клиента завершена. Повторите вход, управление и чат. При ошибках шрифтов сначала запустите просмотр `fix-fonts`, затем решайте, нужен ли перенос.

Далее: [панель FPS, логи и восстановление →](toolkit.md).
