# Словарь без лишней теории

| Слово | Простыми словами |
| :--- | :--- |
| **Wine** | Позволяет Windows-программам обращаться к возможностям Linux. Отдельная установленная Windows не нужна. |
| **Proton / GE-Proton** | Набор на основе Wine с дополнениями для игр. GE — отдельная сборка этого набора. |
| **Runner** | Выбранная в Faugus сборка, которой запускают конкретную игру. |
| **Faugus** | Программа с интерфейсом для добавления игр, выбора Proton и запуска. |
| **Flatpak** | Способ установки Linux-приложений с отдельным окружением и разрешениями. В наших командах используется именно эта версия Faugus. |
| **Префикс** | Папка с отдельным виртуальным диском C: и Windows-настройками игры. Для каждого проекта создавайте свою. |
| **UMU** | Компонент для запуска Proton вне Steam. Faugus использует его при запуске. |
| **Runtime** | Набор Linux-библиотек, который нужен приложению. У Flatpak и UMU свои окружения. |
| **DXVK / Vulkan** | DXVK переводит обращения игры к Direct3D в Vulkan — графический интерфейс, поддерживаемый драйвером Linux. |
| **Wayland / Xwayland** | Wayland управляет окнами рабочего стола; Xwayland позволяет показывать приложения X11 внутри него. |
| **Game ID** | Внутренний идентификатор записи Faugus. Это не номер сервера и не имя аккаунта. |
| **MangoHud** | Необязательная панель FPS, времени кадра и нагрузки. |
| **Лог** | Текстовый журнал запуска. Помогает найти первую ошибку. |
| **EXE** | Исполняемый файл Windows. Установщик и уже установленный лаунчер — разные EXE. |

Не нужно настраивать все эти компоненты вручную. Начните с [Faugus и официального установщика](quickstart.md).
