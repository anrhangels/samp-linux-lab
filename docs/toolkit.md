# Команды, панель FPS и возврат настроек

Начните с `check` и `launch`. Остальные команды нужны только при конкретной проблеме или для настройки панели FPS.

Нужен Python 3.10+. Скрипты используют стандартную библиотеку Python и существующую установку **Faugus Flatpak**. Нативная пакетная версия Faugus этим CLI не поддерживается. Команды выполняются из корня репозитория, без `sudo`.

## Выберите действие

| Задача | Команда |
| :--- | :--- |
| Общая информация | `python3 scripts/samp_linux.py doctor` |
| Найти ID игры | `python3 scripts/samp_linux.py list` |
| Проверить Arizona | `bash scripts/arizona.sh check` |
| Запустить Arizona с логом | `bash scripts/arizona.sh launch` |
| Посмотреть служебные файлы шрифтов | `bash scripts/arizona.sh fix-fonts` |
| Перенести найденное с копией | `bash scripts/arizona.sh fix-fonts --apply` |
| Настроить панель | `bash scripts/arizona.sh hud` |
| Справка | `bash scripts/arizona.sh --help` |

По умолчанию выбран `arizona-launcher`. Для другой записи допишите `--game ВАШ_ID`. Скрипт не создаёт запись Faugus автоматически: выберите и настройте её в интерфейсе.

## Что означает успешный check

`check` проверяет Flatpak, установленное приложение, EXE, префикс, конкретный runner и наличие `umu-run`. Сборка Proton ищется в стандартном пользовательском каталоге Steam, каталоге Steam Flatpak и каталоге Steam внутри данных Faugus; допускается абсолютный путь в поле runner. Нестандартную установку нужно проверить вручную.

Существование файлов на хосте не гарантирует доступ к ним из контейнера. Если проверка пройдена, но запуск не удался, смотрите лог и разрешения Faugus. Команда не проверяет сетевой доступ сервера, аккаунт, античит, Vulkan или реальную передачу микрофона.

## Исправление служебных файлов шрифтов

В тестовой установке рядом с настоящими шрифтами лежали отдельные файлы с именами вроде `font.ttf:Zone.Identifier`. Игра пыталась открыть их как шрифты и показывала ошибки.

Сначала просмотрите список:

```bash
bash scripts/arizona.sh fix-fonts
```

Закройте игру, официальный лаунчер, Faugus и приложения Wine. Затем примените:

```bash
bash scripts/arizona.sh fix-fonts --apply
```

Скрипт ищет внутри `bin/arizona` рядом с установленным лаунчером. Он переносит только обычные файлы `:Zone.Identifier`, у которых рядом существует настоящий `.ttf` или `.otf`. Символические ссылки пропускаются. Основной шрифт остаётся на месте. Если список пуст, ничего исправлять не требуется.

До переноса записывается `restore.json` с планом возврата, затем файлы переносятся в `backups/fonts-ДАТА/files/` с сохранением структуры каталогов. Если операция прервалась, этот план позволяет вернуть уже перенесённые файлы.

Откат при закрытых приложениях:

```bash
bash scripts/arizona.sh restore-fonts --manifest "$HOME/.local/state/samp-linux-lab/backups/fonts-ДАТА/restore.json"
```

Подставьте напечатанный при исправлении путь, включая своё значение XDG_STATE_HOME, если оно настроено. Если лаунчер уже восстановил служебный файл, команда откажется его перезаписывать. После обновления клиента файлы могут появиться снова — тогда повторите просмотр.

## Панель MangoHud

Полностью закройте Faugus и выполните:

```bash
bash scripts/arizona.sh hud
```

Если расширение MangoHud отсутствует, команда сообщит точную команду `flatpak install` для ветки runtime Faugus. Выполните её и повторите настройку. В тестовой сессии использована ветка 26.08; после обновлений не следует выбирать её вслепую.

| Клавиша | Действие |
| :--- | :--- |
| F10 | Минимальный → подробный → скрытый режим |
| F12 | Показать или скрыть панель |
| Левый Shift + F4 | Перечитать конфигурацию |

Минимальный режим показывает FPS и время кадра. Подробный — систему, Proton, CPU/GPU, память, разрешение и рендерер; часть датчиков внутри контейнера может быть недоступна. Панель сервера остаётся на экране. Лимит FPS не устанавливается.

Для совместимости Flatpak/umu создаются локальные копии библиотек MangoHud и манифесты с абсолютными путями. Настройки копируются из `configs/`. ОС, ядро и выбранный runner обновляются при каждом выполнении `hud`. После обновления MangoHud повторите команду. Исходная локальная панель проверена пользователем в игре; обобщённая версия скрипта требует повторной игровой проверки.

## Логи, резервные копии и откат HUD

| Данные | Каталог по умолчанию |
| :--- | :--- |
| Лог каждого запуска | `~/.local/state/samp-linux-lab/logs/` |
| Копии и планы восстановления | `~/.local/state/samp-linux-lab/backups/` |
| Настройки и библиотеки HUD | `~/.local/share/samp-linux-lab/<game-id>/` |
| Записи Faugus | `~/.var/app/io.github.Faugus.faugus-launcher/data/faugus-launcher/games.json` |

Учитываются XDG_STATE_HOME и XDG_DATA_HOME. Для отката HUD закройте Faugus, найдите нужную копию `games.json` в напечатанном каталоге и восстановите её на исходное место. Внимание: полная копия возвращает состояние всех записей на тот момент. Если после неё добавлены другие игры, перенесите только прежние HUD-параметры нужной записи вручную. Локальные файлы HUD можно оставить: после восстановления настроек они не используются, если раньше на них не было ссылок.

## Проверка самих инструментов

```bash
python3 -m unittest discover -s tests -v
bash -n scripts/arizona.sh
```

Тесты проверяют логику настроек, сохранение чужих параметров, перенос файлов и восстановление. Они не заменяют запуск настоящей игры. Скрипты не автоматизируют изменение реестра, драйвера, раскладки или настроек монитора.
