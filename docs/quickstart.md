# С нуля до первого запуска

Цель этого маршрута — установить официальный клиент Arizona и проверить вход на сервер. Если Faugus уже настроен, переходите сразу к [установке игры](arizona.md).

## 1. Подготовьте Linux

Нужны рабочий видеодрайвер с Vulkan, интернет и свободное место для клиента и отдельного префикса. Драйвер устанавливайте по инструкции вашего дистрибутива: универсальной команды для NVIDIA, AMD и Intel нет.

Откройте [официальную настройку Flatpak](https://flatpak.org/setup/), выберите свой дистрибутив и выполните её. Если инструкция просит перезайти в систему, сделайте это.

## 2. Установите Faugus

После настройки Flatpak выполните в терминале:

```bash
flatpak remote-add --user --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak install --user flathub io.github.Faugus.faugus-launcher
flatpak run io.github.Faugus.faugus-launcher
```

Ожидаемый результат — открытое окно Faugus. Дождитесь загрузки его компонентов. В управлении сборками установите GE-Proton и выбирайте конкретную установленную версию. В нашей сессии работала **GE-Proton 11-11**; доступность этой версии и поведение новых сборок могут отличаться.

## 3. Установите Arizona

Продолжите по [пошаговому гайду Arizona RP](arizona.md). Сначала понадобится официальный установщик, затем скачивание клиента через установленный лаунчер.

До первого успешного входа используйте запуск из интерфейса Faugus. Панель FPS и вспомогательные скрипты можно подключить позже.

## 4. Получите инструменты — по желанию

Если есть Git и Python 3.10+:

```bash
git clone https://github.com/anrhangels/samp-linux-lab.git
cd samp-linux-lab
python3 scripts/samp_linux.py doctor
python3 scripts/samp_linux.py list
```

Без Git: на [странице репозитория](https://github.com/anrhangels/samp-linux-lab) нажмите **Code → Download ZIP**, распакуйте архив и откройте терминал в полученной папке.

`doctor` выводит краткую информацию о системе. `list` показывает ваши записи Faugus в формате `ID | название | Proton`. Если записей нет, сначала добавьте игру через Faugus. Отсутствие `nvidia-smi` нормально для компьютера без NVIDIA.

## 5. Проверьте результат

После установки проверьте отдельно:

- Лаунчер открывается, клиент загружен.
- Удалось подключиться к серверу и войти в аккаунт.
- Персонаж ходит на английской раскладке, открывается меню.
- Русский текст отправляется и читается в чате.
- После закрытия повторный запуск работает.

Микрофон проверяйте с другим игроком: подключённый голосовой модуль ещё не подтверждает передачу речи. Если какой-то шаг не прошёл, откройте [таблицу симптомов](troubleshooting.md).
