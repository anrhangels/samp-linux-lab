# Начать играть на Linux

## Что здесь происходит

Windows-лаунчер запускается через Proton. Faugus хранит настройки игры, а umu подготавливает окружение для Proton вне Steam.

| Термин | Простыми словами |
| :--- | :--- |
| Префикс | Отдельная папка с виртуальным диском C: и настройками Windows для игры |
| Runner / Proton | Сборка, которая позволяет Windows-программе работать в Linux |
| Flatpak | Способ установки Linux-приложений с собственным окружением |
| Xwayland | Способ запуска X11-приложений в Wayland-сессии |
| MangoHud | Панель FPS, времени кадра и нагрузки компьютера |
| Game ID | Внутренний идентификатор записи Faugus; это не номер сервера |

## 1. Подготовить систему

Установите драйвер своей видеокарты и поддержку Vulkan по документации дистрибутива. Если Flatpak ещё нет, выберите систему на [официальной странице настройки](https://flatpak.org/setup/). Понадобятся Python 3.10+ и Git — их можно установить через менеджер пакетов дистрибутива.

Добавьте пользовательский Flathub и установите Faugus:

```bash
flatpak remote-add --user --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak install --user flathub io.github.Faugus.faugus-launcher
flatpak run io.github.Faugus.faugus-launcher
```

Дождитесь загрузки компонентов. В менеджере Proton внутри Faugus установите конкретную сборку GE-Proton. В нашей сессии работала 11-11; для воспроизведения используйте её, если доступна. Другие версии требуют самостоятельной проверки. При ошибке Latest смотрите [диагностику](troubleshooting.md).

## 2. Установить игру

Откройте [гайд Arizona](arizona.md#установка-по-шагам). Коротко: официальный Windows-установщик → отдельный префикс → установка → замена пути установщика на установленный EXE → загрузка клиента через лаунчер.

Не создавайте общий префикс для нескольких RP-проектов: их настройки и зависимости могут отличаться.

## 3. Получить инструменты

```bash
git clone https://github.com/anrhangels/samp-linux-lab.git
cd samp-linux-lab
python3 --version
python3 scripts/samp_linux.py doctor
python3 scripts/samp_linux.py list
```

Выполняйте следующие команды из папки `samp-linux-lab`. Если скачали ZIP через GitHub → Code → Download ZIP, распакуйте его и откройте терминал в распакованной папке: Git для этого варианта не нужен.

## 4. Проверить и запустить

```bash
bash scripts/arizona.sh check
bash scripts/arizona.sh launch
```

Если ID записи отличается:

```bash
bash scripts/arizona.sh check --game ВАШ_ID
bash scripts/arizona.sh launch --game ВАШ_ID
```

Проверка не требует пароля. Если клиент ещё не скачан, команда сообщит об этом, а запуск позволит открыть лаунчер и завершить загрузку. Лог сеанса сохраняется автоматически; путь появится в терминале.

## 5. Проверить результат в игре

1. Дождитесь загрузки клиента и зайдите на нужный сервер.
2. Если новая форма регистрации отклоняет отправку, попробуйте отключить «Новую авторизацию» в настройках лаунчера.
3. Переключитесь на английскую раскладку и проверьте передвижение, мышь и чат.
4. Выберите поддерживаемое монитором разрешение в настройках игры.
5. Отдельно проверьте голос с другим игроком, если сервер разрешает его на вашем уровне.

Если появились ошибки шрифтов — используйте [точечное исправление](toolkit.md#исправление-служебных-файлов-шрифтов). Если всё работает, применять дополнительные настройки необязательно.
