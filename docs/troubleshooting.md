# Что делать, если не работает

Найдите свой симптом в таблице. Меняйте один параметр за раз: так будет понятно, что помогло. Переустановка всего префикса обычно стирает полезные данные для диагностики.

## Найдите симптом

| Что происходит | Что проверить сначала |
| :--- | :--- |
| Нет `games.json` | Эти инструменты рассчитаны на Faugus Flatpak. Откройте его и создайте запись игры. |
| Не найден Game ID | Выполните `python3 scripts/samp_linux.py list`, затем добавьте `--game ваш-id`. |
| Запускается установка вместо лаунчера | Замените EXE в существующей записи на установленный `Arizona Games Launcher.exe`. |
| Не найден EXE | Найдите установленный лаунчер внутри `drive_c` своего префикса; [пример пути](arizona.md). |
| Нет Proton или `umu-run` | Дождитесь загрузки компонентов Faugus и выберите конкретную установленную сборку. |
| Ошибки загрузки шрифтов | Выполните просмотр `bash scripts/arizona.sh fix-fonts`; [применение и откат](toolkit.md). |
| Форма регистрации не отправляется | Попробуйте отключить «Новую авторизацию» в лаунчере. Это помогло в нашей сессии. |
| Персонаж не ходит на русской раскладке | Переключитесь на английскую. Постоянного исправления пока нет. |
| Разрешение неверное или клики смещены | Проверьте масштаб Xwayland и верните Xwayland после тестов Wine Wayland. [Наблюдения](arizona.md). |
| Не работает голос | Проверьте выбранный микрофон, разрешения и требования сервера к уровню. Проверьте речь с другим игроком. |
| Мерцают фонари | Проверенного исправления нет. Переключение сглаживания, strict float и GE 11-10 не помогло. |

## Лаунчер пишет «Запуск игры не удался»

Сначала проверьте, не открыта ли уже игра. В нашей сессии она работала и подключалась к серверу, несмотря на сообщение лаунчера. Причина не установлена. Повторное нажатие может запустить лишний экземпляр.

## После заставки Faugus ничего не открывается

Запустите игру с новым логом из папки репозитория:

```bash
bash scripts/arizona.sh check
bash scripts/arizona.sh launch
```

Для нестандартного ID добавьте `--game ваш-id`. Путь к логу появится в терминале. Ищите первую содержательную ошибку, а не только последнюю строку.

В нашей сессии отдельно встречались отсутствие `umu-run` и неудачная загрузка Latest Proton. Наличие одного компонента не подтверждает наличие другого. При HTTP 403 GitHub API повторные запросы подряд не помогают: проверьте доступность [официальных релизов umu для Faugus](https://github.com/Faugus/umu-launcher/releases).

Успешный `check` означает, что основные файлы найдены на хосте. Доступ из контейнера, работа Vulkan и вход на сервер проверяются реальным запуском.

## Не видна панель FPS

1. Выполните `bash scripts/arizona.sh hud` при закрытом Faugus.
2. Если команда попросит расширение MangoHud, выполните напечатанную команду установки и повторите настройку.
3. Полностью перезапустите Faugus.
4. Проверьте ID записи, нажмите F12, затем F10. Убедитесь, что клавиши не перехватываются игрой.
5. Если не помогло, сохраните свежий лог и [создайте отчёт](https://github.com/anrhangels/samp-linux-lab/issues/new/choose).

Ветка расширения должна соответствовать runtime Faugus: не копируйте случайный номер версии из чужого гайда. Наш инструмент определяет её по метаданным и готовит локальные библиотеки для UMU. [Подробности и возврат настроек](toolkit.md).

## Загрузка прерывается из-за простоя компьютера

Проверьте собственные действия сна и выключения, при необходимости включите режим Caffeine. В тестовой системе пользовательская настройка Noctalia выключала компьютер после 25 минут простоя от сети. Это не стандартное поведение всех установок. Погасший экран сам по себе не означает сон.

## Остались зависшие процессы Wine

Закрывайте только приложения нужной игры. Не завершайте все процессы Wine, если параллельно работают другие игры. Старые экспериментальные команды запуска `regedit` через UMU зависали и не включены в инструменты репозитория. Не редактируйте файлы реестра при работающем wineserver: изменения могут быть перезаписаны.

## Что приложить к обращению

Укажите игру и сервер, версии системы, драйвера, Faugus и Proton, точные шаги, первую ошибку и то, что уже пробовали. Используйте [готовую форму](https://github.com/anrhangels/samp-linux-lab/issues/new/choose). Перед отправкой уберите данные аккаунта, чат, токены и личные пути; полный префикс не нужен.
