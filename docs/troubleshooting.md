# Диагностика

## Быстрый поиск по симптому

| Симптом | Первое действие |
| :--- | :--- |
| Скрипт не видит games.json | Убедиться, что установлен Faugus Flatpak и создана запись |
| Не найден Game ID | Выполнить `python3 scripts/samp_linux.py list` и передать `--game ВАШ_ID` |
| Не найден установленный EXE | В записи Faugus выбрать установленный лаунчер внутри префикса |
| Нет Proton или umu | Дождаться загрузки компонентов Faugus; выбрать конкретную установленную сборку |
| Окна ошибок шрифтов | Просмотреть `bash scripts/arizona.sh fix-fonts`; [порядок применения](toolkit.md#исправление-служебных-файлов-шрифтов) |
| Новая регистрация отклоняет отправку | Попробовать старую авторизацию в настройках лаунчера |
| Управление пропадает на русской раскладке | Временно переключиться на английскую; постоянного фикса нет |
| Не то разрешение или смещены клики | Проверить масштаб Xwayland и вернуть Xwayland после тестов Wine Wayland |
| Голос недоступен | Проверить уровень на сервере, микрофон и его разрешения; соединение не равно передаче речи |
| Мерцают фонари | Решение не установлено; не применять старые DXVK-эксперименты как готовый фикс |

## Игра работает, лаунчер пишет об ошибке

В эксперименте лаунчер показывал «Запуск игры не удался», хотя игра работала и подключалась. Вероятна несовместимость проверки процесса с Wine, но причина не установлена. Не нужно повторно запускать игру поверх уже работающей. Код официального лаунчера не изменялся.

## Ничего не происходит после заставки Faugus

Смотрите новый лог запуска. В нашей сессии отсутствовал `umu-run`, затем не находился выбранный Latest Proton. Это разные ошибки. Проверяйте наличие конкретного runner, а не переустанавливайте игру.

При GitHub API rate limit HTTP 403 не повторяйте запросы бесконечно. Если нужен ручной файл umu, используйте релизы [репозитория Faugus/umu-launcher](https://github.com/Faugus/umu-launcher/releases), а не сторонние зеркала. Не публикуйте токены для обхода лимита.

## Панель не видна

1. Установлена ли MangoHud-ветка именно runtime Faugus?
2. Полностью ли перезапущен Faugus после установки расширения?
3. Выполнена ли `hud` для правильного game ID?
4. Нажмите F12 и F10; проверьте конфликт этих клавиш с игрой.
5. Проверьте свежий локальный лог, а не файл от старой сессии.

Пути Flatpak-библиотек `/usr/lib/extensions/...` могут не совпадать с пространством Steam Runtime. CLI готовит локальные копии и манифесты с путями внутри домашнего каталога. Не меняйте системные Vulkan-манифесты.

## Скрипт импорта реестра зависает

Старые экспериментальные команды запуска regedit через umu в этой сессии зависали. Они намеренно не включены в CLI. Не редактируйте `user.reg` и `system.reg` при работающем wineserver: процесс может перезаписать изменения. Не завершайте все процессы Wine подряд, если работают другие игры.

## Сон и выключение во время загрузки

В тестовой системе была пользовательская настройка Noctalia, которая полностью выключала компьютер после 25 минут простоя от сети. Это не стандартное поведение всех установок Noctalia. Перед долгой загрузкой проверьте собственные idle-действия и включите Caffeine. Не считайте обычное погасание экрана доказательством сна компьютера.

## Публикация отчёта

Укажите проект/сервер, версии ОС, ядра, драйвера, Faugus, Proton, разрешение и точные шаги. Сравнивайте один участок при одинаковом качестве графики. Удалите из логов токены, пароли, чат, данные аккаунтов и личные пути. Не прикладывайте полный Wine-реестр или префикс.
